# Choose a record template

Use the template that fits the record. Replace placeholder text before saving a real note. Keep `unknown` where the source cannot answer.

| Template | What belongs here |
|---|---|
| [Meeting](meeting.md) | Source details and a full transcript. |
| [Decision](decision.md) | An accepted or proposed choice and its support. |
| [Project](project.md) | The starting point and links to current records. |
| [Task handoff](task-handoff.md) | The work, evidence, and remaining action. |
| [Report](report.md) | A dated snapshot with links to live task state. |

Keep the same field names across a project. Place records in the agreed folder. Use stable record IDs and relative links. A week folder is a navigation aid, not a requirement for every project.

Keep source text separate from summaries and corrections. Missing speaker labels or timestamps must stay visible. Templates are structures, not evidence that every field has a known answer.
