# Instructions to adapt this kit

Copy the request below into your agent. Give it the path to this kit and the project you want to use.

> Read this kit and inspect my existing project instructions, notes, and templates. Work only within the access I give. Keep my established folder names and existing content.
>
> Map the source records, current decisions, and task state to their editable locations. Reuse the existing records where possible. Explain any missing connection before claiming you can read it.
>
> Propose the smallest useful adaptation for one project. Include a project entry note and templates for the records this project actually needs. Keep sources intact. Attach corrections separately. Leave unknown dates, speakers, owners, and approvals unresolved.
>
> For a task board, search before creating a task. Read a task before changing it. Keep the current task status on that board and link to the notes that explain the work. A report is a dated snapshot.
>
> After authorized changes, verify local links and show the files that changed. Tell me how to start a new session with the same access. Give me a question I can ask without including its answer. Do not publish files, install services, or change account settings as part of this adaptation.

This request does not grant access to private folders or remote services. Check the changes before with the adapted records for consequential work.
