fluxcache is an open-source TypeScript library for semantic caching in large language model (LLM) applications. A normal cache matches requests by exact text. A small change in wording then causes a cache miss. fluxcache compares the meaning of a new prompt with the prompts already in the cache. If two prompts are close enough in meaning, fluxcache returns the stored response instead of a new call to the model. This lowers the number of calls to the model and cuts the cost and response time of the application.

fluxcache works with common embedding providers and vector stores. Teams can add semantic caching to an existing stack without a rewrite. The library ships with complete TypeScript types and a small API surface. A new user can set up a cache in a few lines of code. Developers can set the similarity threshold, the time-to-live for each cache entry, and the storage backend. The project is open source, and the community can report issues, suggest features, and submit changes on GitHub.
