fluxcache is an open-source TypeScript library for adding semantic caching to LLM applications. Instead of caching only exact prompt matches, fluxcache stores and retrieves responses based on meaning, helping your app reuse previous completions when users ask similar questions. It is designed for chatbots, agents, RAG pipelines, support tools, and any workflow where repeated or semantically equivalent requests can be answered faster and more cost-effectively.

Built for modern TypeScript projects, fluxcache provides a simple API for embedding prompts, matching similar queries, and managing cached LLM outputs. It helps reduce latency, lower model usage costs, and improve consistency without forcing you to rewrite your application architecture. Whether you are prototyping locally or scaling a production AI system, fluxcache gives you a practical foundation for intelligent response reuse.
