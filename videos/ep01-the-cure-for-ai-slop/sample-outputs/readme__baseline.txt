fluxcache is a TypeScript library that adds semantic caching to LLM applications, letting you cache and reuse responses based on the *meaning* of a request rather than an exact string match. Traditional caches miss constantly in LLM workloads because users rarely phrase the same question identically — fluxcache solves this by embedding incoming prompts and matching them against previously cached queries within a configurable similarity threshold. The result is fewer redundant calls to your model provider, lower latency for your users, and a meaningful cut in inference costs, all without giving up control over correctness.

Built with a pluggable architecture, fluxcache works with any embedding provider and any storage backend — from an in-memory store for local development to Redis, Postgres with pgvector, or a dedicated vector database in production. It ships with sensible defaults so you can get semantic caching running in a few lines of code, while exposing the knobs — similarity thresholds, TTLs, namespacing, custom scoring — that real applications need as they scale. Whether you're building a chatbot, a RAG pipeline, or an agentic workflow, fluxcache is designed to slot into your existing stack with minimal friction and no vendor lock-in.
